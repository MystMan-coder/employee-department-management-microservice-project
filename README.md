# Employee & Department Management Microservices

## Overview
This project demonstrates a microservice-based approach to managing **Employees** and **Departments** using **Spring Boot**. It showcases:

- Entity to DTO mapping using **ModelMapper** and **MapStruct**
- RESTful APIs for CRUD operations
- Clean architecture and separation of concerns
- Ready for microservices and scalability

## Tech Stack
- **Java 17 / 20**
- **Spring Boot 3**
- **Spring Data JPA**
- **ModelMapper & MapStruct**
- **MySQL / H2 Database**
- **Lombok**
- **Maven**
